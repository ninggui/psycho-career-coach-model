# psycho-career-coach-model

**双角色评估：资深心理咨询师 + 职业发展规划师，从长对话记录出结构化自我认知。**

<p>

## 输入输出

- 输入：你和 AI 的长对话/语音转文字记录
- 输出：人格画像 + 心理状态 + 职业路线 + 岗位匹配 + 求职建议

## 流程

原始记录 → 清洗保留原话 → 双角色提示词 → 多轮深挖 → 结构化报告
